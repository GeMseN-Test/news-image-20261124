# Tuesday 24 November 2026 — World News in One Image

Entry for the make.fun bounty **"Sum up 24 November's world news in one image"**
(https://make.fun/bounty/news-image-20261124).

`main.py` (Python 3.13, standard library only, no network) draws a single
1024×1024 PNG to `/output/entry.png`: 36 date-checked stories, 7 regions,
a UTC timeline, a pinned world map, a big-numbers strip and a DATE CHECK box.

Building in progress — full front page coming shortly.
